# ナミヤ雑貨店（1:64）— FDM／光固化分工（無雷射切割）

| 零件 | 方式 | 原因 |
|---|---|---|
| 主屋牆殼、店面殼體、樓板、陽台板、矮屋、地形基座 | **FDM** | 大面、厚 ≥2mm，強度好、便宜 |
| 屋頂（脊線切兩片，平放） | **FDM** | 底面朝下免支撐；瓦紋用貼片 |
| 室內隔間牆 | **FDM** | 平放或直立皆可 |
| 樓梯、屋架 | **光固化**（太細時自動改） | 最細約 0.8mm |
| 磚牆／屋瓦貼片 | **光固化** | 浮雕細節 FDM 印不出；平放貼在 FDM 殼外 |
| 欄杆、窗格、玻璃、鐵捲門、雨遮、招牌字、排水管、櫃台貨架 | **光固化** | 0.1～1mm 細件 |

## 沒雷射切割怎麼輸出
1. 按「📦 匯出分件包」→ zip 內分 `FDM/`、`光固化/` 資料夾＋README。
2. FDM：0.2mm 層高、牆 4 圈、填充 15%；STL 已轉 Z 向上貼平台。
3. 光固化：細件立放傾斜 15° 加支撐；貼片平放浮雕面朝上；超出平台的件（如磚牆貼片）需再切小片（可分面匯出「貼皮薄片」）。
4. 組裝：FDM 殼 → 貼磚／瓦 → 上色 → 貼窗、欄杆、鐵捲門、雨遮、招牌。
